# Radio Operator — Agent-specific Rules

- Track enemy route by drawing announced enemy courses on a transparent sheet.
- Slide/translate the transparent sheet to estimate enemy position, ensuring routes do not cross islands or impossible areas.
- Use drones and sonar results (when activated) to narrow down enemy position and advise Captain.
